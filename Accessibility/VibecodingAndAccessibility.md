# Vibecoding and Accessibility: Super Power AND worst nightmare

Let's look trough the lens of accessibility to see if vibecoding is a super power or the worst nightmare in software evolution.

Using AI-tools like Github Copilot, Claude Code and a bunch of other tools to write code is a super power for developers. With agentic coding we can do even more and we reaching the era of non-coders are vibecoding their ideas. It sounds like the nightmare for professional software developers. Non-developers making applications.

To be honest: this is not as new as we think. Wix and Canva are already doing this for years. And they are not the only ones. Wordpress, Shopify and even Microsoft Power Apps are using the same concepts: applications build by non-coders. Let's call them citizen devs, power users and  business people.

When I examine what the majority of creators with those tools build I see unacessible layouts, bad color contrast and low general design quality. This is not a surprise. They are not trained in design, accessibility and user experience.

On the other hand I see people building stuff with vibecoding or easy to use tools who were not able to afford a professional developer. Some of them are even building assistive technologies or marketing their human centered solutions to a wider audience.

In this talk we will discover what is needed in in a world of vibe coding to increase the web content accessibility!
